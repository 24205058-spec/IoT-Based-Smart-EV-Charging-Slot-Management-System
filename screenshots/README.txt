======================================================================
IoT-Based Smart EV Charging Slot Management System - Screenshots Guide
======================================================================

This directory is designated for saving visual artifacts and screenshots 
of the running application for project reports, viva presentations, 
and documentation.

Recommended screenshots to capture:
1. 01_main_dashboard_overview.png
   - Full view of the EV CHARGING HUB header, simulation banner, and 6 KPI cards.
2. 02_live_slots_grid.png
   - The 10 charging slots (EV01 to EV10) highlighting statuses:
     AVAILABLE (Green), CHARGING (Gold with glow), COMPLETED (Gray), FAULT (Red).
3. 03_natural_language_search.png
   - Interactive search queries and structured result displays (e.g. "status of EV03",
     "show EVs below 30% battery", "available charging slots").
4. 04_live_charging_monitor_events.png
   - Real-time active charging sessions table alongside the recent events audit stream.
5. 05_historical_analytics_plotly.png
   - Interactive Plotly visualizations (Daily Sessions, Energy Consumption,
     Fleet Distribution, Slot Utilization, Battery Distribution, and Charging Duration).
6. 06_nodered_flow_simulator.png
   - Node-RED workspace showing the 'EV CHARGING IoT SIMULATOR' flow with active
     inject nodes, function logic, and debug telemetry outputs.
